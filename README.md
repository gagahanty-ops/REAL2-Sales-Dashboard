# РЕАЛ ДВА — дашборд отдела продаж

Внутренний аналитический дашборд, который читает данные amoCRM через внешнюю OAuth-интеграцию, рассчитывает показатели отдела продаж и обновляет только отдельную копию существующей Google-таблицы.

## Статус

Слои `PROJECT_IDEA` и `SPEC` утверждены заказчиком 2026-09-12. Конфигурационный пакет и пять исполнимых планов подготовлены; код приложения ещё не создавался.

Принятые ограничения:

- amoCRM остаётся единственным источником истины по сделкам;
- интеграция с amoCRM является внешней OAuth-интеграцией;
- прикладные запросы к amoCRM работают только через `GET`;
- единственный разрешённый `POST` в домен amoCRM — обмен и обновление OAuth-токена;
- приватная интеграция amoCRM не используется;
- исходная Google-таблица `123QVhKGG3Y6ZlyHYnuKG_1BPhS82FcYaqY96nsB7Iks` никогда не редактируется;
- публикация возможна только в отдельную копию таблицы;
- до приёмки система работает в теневом режиме и не меняет рабочий процесс отдела продаж.

## Термины

- **лид** — сделка amoCRM в целевой воронке;
- **заявка** — лид, который впервые достиг этапа «Завершение (самовывоз или доставка)»;
- **оплата** — лид, который впервые достиг статуса «Успешно реализовано»;
- **дата отчёта** — календарная дата создания лида в часовом поясе `Europe/Moscow`;
- **публикация** — атомарная замена расчётного диапазона в разрешённой копии Google-таблицы;
- **теневой режим** — чтение и расчёт без записи в Google Sheets.

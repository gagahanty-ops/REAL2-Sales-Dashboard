# REAL2 Project Memory Vault

Переносимая память проекта [[REAL2 дашборд отдела продаж строится как read-only зеркало amoCRM]]. Цель: другой агент открывает эту папку, за пять минут понимает проект и продолжает работу, не расспрашивая владельца заново.

Память лежит внутри рабочего репозитория (`project-memory/`). Код и память передаются вместе одним репозиторием — отдельного vault, snapshot или вложенного git внутри нет.

## Первые пять минут

1. [[текущие приоритеты и точка продолжения]] — где проект стоит прямо сейчас и что делать следующим.
2. [[как продолжить проект новому агенту]] — команды окружения, рабочий метод, запреты. Это инструкция, а не описание.
3. [[проект нельзя ломать в amoCRM и нельзя трогать исходную Google таблицу]] — запреты владельца, нарушать нельзя ни при каких условиях.
4. [[архитектура проекта REAL2 разделена на web worker db integrations domain testkit]] — техническая карта.

Перед тем как трогать код, открой `raw-context/project-docs/SPEC.md`, `METRICS_CATALOG.md`, `SECURITY_READ_ONLY.md` и активный план в `raw-context/project-docs/docs/superpowers/plans/`.

## Raw context

`raw-context/` — первичные материалы, которые не надо пересказывать по памяти:

- `raw-context/project-docs/` — копии нормативных документов проекта;
- `raw-context/project-docs/docs/superpowers/plans/` — все исполнимые планы;
- `raw-context/sdd/` — журнал SDD, брифы задач, отчёты и диффы ревью;
- `raw-context/guide/` — руководство, по которому построено хранилище.

Если копия в `raw-context/` разошлась с живым репозиторием, истина — живой репозиторий.

## Как поддерживать память

Правила дописывания — в `../project-memory/CLAUDE.md`. Коротко: в конце сессии заметка в `sessions/`; новое решение — в `knowledge/decisions/`; найденная или закрытая ошибка — в `knowledge/debugging/`; переиспользуемый приём — в `knowledge/patterns/`; изменилась точка продолжения — правь [[текущие приоритеты и точка продолжения]].

Секреты, токены, значения переменных окружения и персональные данные клиентов в это хранилище не попадают никогда. Репозиторий публичный.

## 3. План 3, задачи 3–7

Все задачи шли по TDD: красный тест → реализация → ручные мутации → полный гейт → коммит → отчёт в `.superpowers/sdd/2026-09-12-03-normalization-metrics/` с зеркалом в `project-memory/raw-context/sdd/`.

### Задача 3 — таймлайны и вехи (`05958bb`, `9982319`, `46fc2dc`)

Файлы: `packages/domain/src/leads/build-history.ts` (+тест), `packages/db/src/normalize-run.ts`, `apps/worker/src/jobs/normalize-sync-run.ts` (+интеграционный тест).

`buildLeadHistory` упорядочивает события стадий и ответственных по канонической метке времени, затем по `amoEventId`; дедуплицирует; берёт **первое** наблюдение для вех (`application`, `won`); строит таймлайн ответственного (при создании / на заявке / на выигрыше / текущий); считает длительность закрытых стадий и возраст открытой относительно `snapshotAt`. Вместо выдумывания вехи поднимает проблему качества. Severity: `duplicate_event=info`, `invalid_event_time=blocking`, `malformed_event_payload=warning`, `missing_stage_history=blocking`, `stage_history_conflict=warning`.

**Главный разворот задачи.** Первая диагностика была неверной: агент решил, что воркеру не хватает прав, и выдал миграцию `0011_normalization_write_grants.sql` с `update/delete` на `lead_stage_events`, `lead_responsible_events` и `delete` на `leads`/`lead_milestones`. Тесты позеленели, но решение нарушало инвариант «история только на добавление», закреплённый security-тестом задачи 1 и запретом каталога метрик удалять проблемные сделки ([1262], [1332], [1335]). Миграция **отозвана**, запись переписана на append-only, а лид, ушедший из настроенной воронки, теперь остаётся в нормализованном слое и получает эскалированную проблему качества; поле результата `leadsRemoved` переименовано в `leadsOutOfScope` ([1339]). Проверено на БД, пересозданной `supabase db reset` только из миграций. Связано с [[сырые amoCRM страницы append only и курсор двигается только после полного success]].

Мутации: 7 по домену + 8 по БД/воркеру — все пойманы. Гейт: unit 366/366, integration 96/96, security 24/24, db lint чисто.

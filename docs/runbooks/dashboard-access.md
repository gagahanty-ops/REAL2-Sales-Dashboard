# Доступ к дашборду REAL2

Дашборд закрыт: публичной регистрации нет, роли выдаёт только admin, а
manager видит исключительно свои сделки. Этот runbook описывает выдачу
доступа, проверку прав и локальный прогон E2E-гейта.

## Роли

| Роль | Что видит | Что может менять |
| --- | --- | --- |
| `admin` | весь отдел, настройки, качество, планы | пользователей, конфигурацию, планы, приёмку проблем |
| `head` | весь отдел, качество, планы | ничего из перечисленного |
| `manager` | только сделки, где он текущий ответственный | ничего |

Manager без привязки к пользователю amoCRM (`amo_user_id`) получает
`E_CONFIG_INCOMPLETE`: это не ошибка интерфейса, а незавершённая настройка.

## Выдача доступа

1. Admin заводит пользователя в `/settings/users`, указывая роль и, для
   менеджера, его `amo_user_id` из amoCRM.
2. Пароль задаётся при создании; повторная выдача пароля — это новая
   операция admin, а не восстановление через почту.
3. Отключение доступа — флаг «неактивен». Строки истории остаются: снимки
   неизменяемы, и удаление пользователя не переписывает отчёты.

## Как проверить границы прав

```bash
# менеджер не может подменить чужой ключ
curl --fail-with-body \
  "http://127.0.0.1:3000/api/dashboard/drilldown?from=2026-09-01&to=2026-09-30&manager=amo:84"
# ожидается 403 E_FORBIDDEN для сессии другого менеджера
```

В интерфейсе: менеджер открывает `/managers` и видит только свою строку;
ссылка руководителя с чужим `manager=amo:<id>` даёт 403, а не чужие данные.

## Локальный E2E-гейт

```bash
supabase start
pnpm build
set -a; . ./.env.e2e; set +a
pnpm exec playwright test
```

`.env.e2e` не хранится в репозитории и содержит только локальные ключи.
Прогон поднимает собранное приложение на `127.0.0.1:3100`, засевает
синтетические личности и один утверждённый снимок. Оба внешних флага
(`SYNC_ENABLED`, `SHEET_PUBLISH_ENABLED`) остаются `false`, поэтому ни один
запрос в amoCRM или Google из тестов невозможен.

Что проверяет гейт:

- границы ролей в интерфейсе, в API и в CSV-экспорте;
- четыре состояния экрана: загрузка, ошибка с идентификатором запроса,
  пустой период и данные;
- фильтры в адресе: перезагрузка, кнопка «назад», общая ссылка;
- доступность: один заголовок первого уровня, именованные ориентиры,
  работа с клавиатуры, видимый фокус, текстовый эквивалент графика;
- бюджеты ответа на засеянном профиле.

## Перед выдачей доступа сотрудникам

- баннер свежести показывает реальную версию снимка и время источника;
- каждая агрегированная цифра сходится с drill-down по тем же фильтрам;
- независимый проверяющий подтвердил маскирование телефонов и поведение RLS.

Публикация в Google Sheets на этом этапе не выполняется.
